# Personal Portfolio

เว็บ Portfolio แบบ Static ใช้ HTML + CSS + JavaScript

## โครงสร้าง
- index.html
- style.css
- script.js
- assets/

## วิธีใช้งาน
เปิด `index.html` ด้วย Browser ได้ทันที

## จุดที่ควรแก้ก่อนนำไปใช้
1. เปลี่ยน `Your Name` เป็นชื่อจริง
2. เปลี่ยน Email
3. ใส่ลิงก์ GitHub / Social Media
4. เพิ่มรูปโปรไฟล์ใน `assets/`
5. แก้รายละเอียด Skills และ Projects ให้ตรงกับข้อมูลจริง
